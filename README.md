# Ejercicios de Programación Orientada a Objetos (POO)  

Este repositorio contiene una colección de ejercicios prácticos para aprender y reforzar los conceptos de **Programación Orientada a Objetos (POO)** en JAVA.  

Cada carpeta incluye un ejercicio temático con su propio `README.md` explicando los pasos a seguir.  
Por ejemplo, en la carpeta `animales/` encontrarás un ejercicio sobre una página de adopción de animalitos.  

---

## 🚀 Cómo clonar este repositorio  

Para obtener una copia local del repositorio, utiliza el siguiente comando en tu terminal:  

```bash
git clone https://github.com/amaurelia/Programaci-n-Orientada-a-Objetos.git
```
